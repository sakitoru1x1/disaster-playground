# CHARACTER ART PASS 1.0 — техническое задание и приёмка

**Тип проекта:** существующая браузерная 3D-игра Disaster Playground (Babylon.js / Havok / Vite).
**Цель:** убрать технические человекообразные заглушки в одном цельном патче.
**Визуальный стиль:** стилизованные игровые фигурки с гладкими округлыми пропорциями, лёгкой низкополигональной гранёностью, яркой одеждой и легко читаемыми профессиями. **Не концепт-арт и не фотореализм.**

## Реализуемые персонажи
1. Мирные жители: взрослый мужчина / взрослая женщина / подросток / ребёнок / пожилой. Модели должны отличаться масштабом тела, силуэтом одежды, разнообразными причёсками, не только цветом рубашки. Включить кожу пяти оттенков, восемь оттенков верха, пять видов брюк и минимум три цвета обуви, различные прически.
2. Пожарные: каска, яркая куртка и световозвращающая полоска, тёмные брюки, обувь. Визуально отличимы издалека, даже без надписи.
3. Медики: светлая медицинская форма, цветной акцент и узнаваемый головной убор или медицинский знак. Должны сохраниться анимации выгрузки из скорой, подхода к пациенту, работы с носилками.
4. Строители: защитная каска, яркая сигнальная форма, рабочие брюки. Использовать ту же систему конечностей для движения вокруг строительного участка.

## Геометрия
- **Без грубых прямоугольных туловищ и кубических голов.** Геометрия: низкополигональные сферы, цилиндры с зауженной талией, отдельные ботинки, шея, уши и нос; волосы и индивидуальные элементы одежды.
- Минимум две читаемые детали лица (глаза/нос), минимум 4 узнаваемые причёски, вплоть до длинных волос, чёлки, короткой причёски.
- Анимационный риг: отдельные вращающиеся центры плеч, бёдер и головы. Во время ходьбы/паники ноги и руки движутся в противофазе. На остановках появляется лёгкий поворот головы и жесты.
- Рост и пропорции: ребёнок около 78% роста взрослого, подросток около 90%, пожилой около 95%. Масштаб влияет на все составные элементы персонажа.

## Совместимость существующих игровых систем
- `world.civilians`, `root`, `legs`, `arms`, `help` и существующие `person head / person torso / person arm / person leg` должны оставаться доступными.
- Havok ragdoll использует существующие материальные стили кожи и одежды персонажа, а травмированные и переносимые граждане продолжают правильно переключать состояния.
- Медики, строители и пожарные получают тот же процедурный скелет и общее оформление, но различаются формой.
- Новые жители после восстановления здания должны использовать те же модели без создания новой системы геометрии.

## Производительность
- Геометрия, которую используют десятки или сотни NPC, создаётся как **master + InstancedMesh**. Персонажи используют ограниченную общую палитру материалов. Не создавать уникальный меш и текстуру на каждого NPC.
- Бюджет населения остаётся 72 жителя на телефоне и 210 на ПК, плюс ограниченное количество профессиональных NPC; нет «вечных» временных объектов после пересоздания города.
- Штатная мобильная настройка SHARP MOBILE остаётся активной. Не изменять Havok и логику городских катастроф в рамках арт-патча.

## Проверки и критерии приёмки
1. На **реальном рендере игры** видны отличающиеся возрастом и прической жители, медик, пожарный, строитель. Нельзя выдавать AI-арт или внешние референсы за результат работы.
2. Скриншоты должны быть сделаны Playwright/Chrome с запущенного Vite и Babylon.js. Для удобства сравнения допустима **открыто обозначенная внутриигровая QA-расстановка** из настоящих игровых моделей, но не внешняя композиция, нарисованная вне движка.
3. Проверить Desktop Chrome и Chrome Android emulation. Тестировать наличие фрагментов, материалов, движение ригов, анимацию травмированных и вызов спасателей.
4. `npm run build`, базовые unit suites, `npm run test:browser`, `npm run test:dispatch:e2e`, `npm run test:citizen-ragdolls:browser`, отдельный `npm run test:character-art` должны проходить.
5. Скриншоты и это техзадание сохраняются в репозитории **вместе с одним commit для Character Art Pass 1.0**. При утверждении результата они являются ground truth, а не художественным обещанием.

## Текущие ограничения
Процедурные примитивы с округлыми пропорциями — это качественно оформленный stylized low-poly, но не профессионально скульптированные FBX/GLB-модели с лицевой мимикой и ручной анимацией. Браузерные тесты на программном WebGL не являются замером FPS на физическом телефоне.
